# CF7 MJML

A feature of [WP-Go](../../README.md), off until turned on in the WP-Go screen.

Contact Form 7's mail bodies, written in MJML. In the Mail tab, the Message body of Mail and of
Mail (2) moves into a Monaco editor beside a live preview, with a toggle over them. Off, the editor
is the body itself, as HTML or, with CF7's "Use HTML content type" off, plain text. On, three
tabs: the MJML in a Monaco editor with completions, the preview, and the compiled HTML. Every edit compiles in the browser
(`mjml-browser`) into the hidden textarea, so CF7 still saves and sends HTML. Nothing in the
feature runs when a mail goes out.

The MJML source is kept in the form's `_wp_go_mail_mjml` meta, set to `copy-once` in
`wpml-config.xml` (read by WPML and WP-Go Languages alike). A form saved while this lived in the
theme has it as `_wg_mail_mjml`: that is read when the new key is missing, and moved to it on the
form's next save.

Turning the feature off leaves every body as the HTML its MJML last compiled to.

## Files

| | |
|---|---|
| `cf7-mjml.php` | the feature: enqueues the editor on CF7's editor page, saves the meta |
| `src/mjml.js` | the editor: toggle, tabs, compile, full screen |
| `src/language.js` | the MJML language for Monaco: tokens and completions |
| `src/schema.json` | what the completions know, generated by `src/schema.mjs` |
| `src/mjml.scss` | the editor's styles, in wp-admin's own look |
| `vite.config.js` | the editor's build, into WP-Go's `dist/cf7-mjml/`, **committed**: the feature runs without one |

## Building

Its own Vite config (`vite.config.js`), run by WP-Go's build with the other features', into
WP-Go's `dist/cf7-mjml/` ([Building](../../README.md#building)):

```sh
cd ../wp-go
yarn               # once
yarn build         # commit dist/
yarn watch         # rebuild on save while working on it
yarn schema:mjml   # after upgrading mjml / mjml-browser
```

The build writes three files: `mjml.js` and `mjml.css`, with fixed names, so the PHP needs no
manifest, and Monaco's icon font, `codicon-<hash>.ttf`, which `mjml.css` points to. Monaco's
lazily loaded language definitions are inlined into `mjml.js`, not split into chunks: a chunk
imports `./mjml.js` back, a URL other than the `mjml.js?ver=…` WordPress loads, and the browser
would run the editor twice.
